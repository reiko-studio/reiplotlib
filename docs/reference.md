# API reference

The reference follows the Python package. Each page includes signatures,
docstrings, and source code; the search box there searches the API itself.

Start with the [public `reiplotlib` interface](api/reiplotlib.html), or browse a
module directly:

| Module | Contents |
| --- | --- |
| [Colors](api/reiplotlib/colors.html) | Named families, `NamedColor`, and neutrals |
| [Palettes](api/reiplotlib/palettes.html) | Categorical palettes and property cycles |
| [Color scales](api/reiplotlib/colorscale.html) | Shared numeric mappings and matching colorbars |
| [Style](api/reiplotlib/style.html) | `apply_style` and `rc_context` |
| [Layouts](api/reiplotlib/layouts.html) | Journal widths and sized subplots |
| [Options](api/reiplotlib/options.html) | Keyword presets for Matplotlib artists |
| [Plotting](api/reiplotlib/plotting.html) | Adaptive error bars and shaded bands |
| [Series](api/reiplotlib/series.html) | Stable styles keyed by series identity |
| [Legends](api/reiplotlib/legends.html) | Shared entries, grouped legends, and in-panel legends |
| [Axes](api/reiplotlib/axes.html) | Panel labels, axes cleanup, and percentage formatting |
| [Secondary axes](api/reiplotlib/secondary.html) | Converted x/y coordinates with visible ticks |
| [Autoscaling](api/reiplotlib/autoscale.html) | Y limits fitted to the visible x range |
| [Export](api/reiplotlib/export.html) | Save figures in one or several formats |

The API opens in pdoc's reference layout. Its **Guides and examples** link brings
you back here.
